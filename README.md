# SC科目Bドリル

情報処理安全確保支援士試験 **科目B（旧午後）** の過去問を、スマホで「読む → 書く → 自己採点」できるWebアプリです。GitHub Pagesでそのまま動きます（ビルド不要の静的サイト＋取り込み用のGitHub Actions）。

## できること

- **設問を1つずつ解く**：入力 → 「解答して解説を見る」で、その設問のIPA解答例・解説・関連語がすぐ出る → ○△×で自己採点 → 次の設問へ
- 全25問・252設問に、設問ごとの解答例（IPA）・独自解説・関連語を収録（`data/notes/<回>.json`）
- 用語集210語（`data/glossary.json`）。関連語をタップで解説と「その用語が出る設問」を表示。△×が付いた設問の用語を「復習したい用語」として表示

- IPA公開の過去問（R5秋〜R7秋の午後、R5春の午後Ⅰ・Ⅱ）を問ごとに分割して表示（ページ画像・タップで拡大）
- 設問から解答欄を自動生成し、字数制限つきの欄は「◯/40字」でカウント（超過は赤）
- IPAの解答例・出題趣旨・採点講評を問ごとに表示し、各解答欄を ○ / △ / × で自己採点
- 問ごとのタイマー（新形式は75分、旧午後Ⅰは45分、旧午後Ⅱは120分が目安）
- 解答履歴と正答率、学習データのJSON書き出し／読み込み（端末移行用）
- オリジナル演習3問（Web／OAuth・OIDC／インシデント対応、模範解答・解説つき）
- PWA対応（ホーム画面に追加、一度開いた問題はオフラインでも表示）

## 公開手順（GitHub Pages）

1. `main` にpushすると、Actions「Build & Publish (gh-pages)」がサイトを作って `gh-pages` ブランチに出力する
2. GitHub Pagesは `gh-pages` ブランチから配信（表示されないときは **Settings → Pages → Source** を「Deploy from a branch」「gh-pages / (root)」にする）
3. `https://<ユーザー名>.github.io/<リポジトリ名>/` をスマホで開き、ホーム画面に追加

ワークフローがIPAのPDFを取得 → `pdftoppm` で画像化。問題冊子は文字情報のないスキャンPDFなので、Tesseract（日本語）でOCRして問の区切りと設問を読み取り → `data/catalog.json` を生成してデプロイします。**PDFや画像はリポジトリにコミットしません。**

## 過去問を追加する

`scripts/sources.json` に年度を1件足してpushするだけです。URLは [IPAの過去問題ページ](https://www.ipa.go.jp/shiken/mondai-kaiotu/index.html) の年度別ページから。

## 手元で動かす

```bash
sudo apt install poppler-utils tesseract-ocr tesseract-ocr-jpn && pip install pillow
python3 scripts/build_pastexams.py          # IPAから取得して data/ を生成
python3 -m http.server 8000                  # http://localhost:8000/
```

## 注意

- 解答欄はOCRした「設問」から作っています（空欄記号 a, b… は1つの欄にまとめています）。ずれたら解答画面の「解答欄を追加」で補ってください。
- 解答例テキストはPDFから抽出したもので、表の崩れが出ることがあります。そのときは「解答例PDFの画像」を見てください。
- 採点は自己採点の目安です（IPAは配点・採点基準を公表していません）。

## 出典・著作権

過去問題・解答例・採点講評の著作権は独立行政法人情報処理推進機構（IPA）にあります。IPAの「過去問題の使用」に関する案内に従い、各問題に「出典：令和7年度 秋期 情報処理安全確保支援士試験 午後 問1」の形式で出典を表示しています。内容は改変していません（PDFをページ単位で画像化・テキスト抽出して表示）。

オリジナル演習はIPAの試験問題ではありません。解説・関連語・用語集はヤマネックスによる独自のもので、IPAの公式見解ではありません。
